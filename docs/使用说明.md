# MIhonW 使用说明（WebDAV 云盘 + 超分版 + 文件夹视图）

> 适用版本：`MIhonW.apk`（包名 `app.mihon`，应用显示名「mihonW」）
> 本版本在官方 Mihon 基础上内置了两项增强：**WebDAV 云盘阅读源** 和 **本地超分（画面增强）**。
> 本文只讲这两块怎么用，其余阅读/书架/扩展功能与官方 Mihon 一致。

---

## 一、把漫画放到 WebDAV 服务器上（目录规范）

「WebDAV 云盘」源读取的是你**已有的** WebDAV 服务器目录，不会自动帮你整理文件。请按下面结构摆放：

```
目标目录/
├── 漫画A/
│   ├── cover.jpg          ← 封面（可选，见下方说明）
│   ├── 第1话.cbz
│   ├── 第2话.cbz
│   └── 第3话.cbz
├── 漫画B/
│   ├── cover.webp
│   └── 单话.cbz
└── …
```

要点：

- **每个漫画是一个文件夹**，文件夹名就是漫画标题。
- 文件夹里的章节支持 **10 种格式**：压缩包 `zip`/`cbz`/`rar`/`cbr`/`7z`/`cb7`/`tar`/`cbt`、电子书 `epub` 与 `pdf`，按文件名排序识别为「章节」。
- **PDF 也能读**：用 Android 系统内置的 PDF 渲染器逐页渲染成图片，**不联网、不增大安装包**。扫描版漫画 PDF（每页一张图）观感等同原图，矢量/文字型 PDF 同样能正常显示。加密或损坏的 PDF 打不开；PDF 章节不会自动生成缩略图。
- **封面**：在每个漫画文件夹里放一张名为 `cover` 的图片即可，支持 `cover.jpg / cover.jpeg / cover.png / cover.webp`。不放封面也能读，只是书架里没有缩略图。
- 文件夹**层数不要嵌套**：WebDAV 源只认「目标目录的直接子目录」为漫画，子目录里的子目录不会被递归展开。
- 文件名里的 `+`、空格、`#` 等特殊字符都能正常处理，不用担心。

## 二、在 App 里配置 WebDAV

### 第 1 步：开启并填写云同步账号

1. 打开 App，进入 **「更多」→「设置」→「下载」**。
2. 找到 **「云同步」** 区块：
   - 打开 **「云同步」总开关**。
   - 点击 **「云同步」** 条目，在弹出的登录框里填：
     - **WebDAV 地址**：例如 `https://dav.example.com/dav` 或 `http://192.168.1.10:5005`（填到根或你常用的目录都行，后面第 2 步再选具体目录）。
     - **用户名 / 密码**：你的 WebDAV 账号。
   - 点 **「测试连接」**：提示「连接成功」说明地址和账号没问题；失败会给出具体错误（多为地址少写了路径、或账号无权限）。
3. 回到「下载」页，确认顶部状态显示「已连接（你的用户名）」。

> ⚠️ **必须先开总开关并填好账号**，否则「WebDAV 云盘」源里是空列表。

### 第 2 步：选择漫画所在目录

1. 在「下载」页的「云同步」区块，点 **「云同步目录」**。
2. 进入目录树选择器：
   - 根目录默认展开，点文件夹左侧箭头可逐级展开（**懒加载**，只展开你点开的那一层，不会一次性拉整棵目录树）。
   - 点文件夹名把它**选中**（右侧出现对勾）。
3. 选好后点右上角 **「选择」** 保存。

这个目录就是上一节说的「目标目录」，App 会把它下面的直接子目录当作漫画。

### 第 3 步：去「浏览」页看书

- 回到底部 **「浏览」** 标签，列表里有一个内置源 **「WebDAV 云盘」**（语言标记为 `other`，与「本地」源平级，无需安装扩展、默认启用）。
- 点进去就是你的漫画列表。封面是**滑到才加载**（懒加载），列表不会因几十上百本漫画而长时间转圈。

## 三、WebDAV 云盘的排序与筛选

- 顶部有两个标签：**「热门」** 和 **「最新」**。
  - 「最新」默认按**目录的修改时间倒序**（最近改过的漫画排前面）。
  - 「热门」默认保持服务器返回的原始顺序。
- 点右上角 **筛选（漏斗）图标**，里面有 **「排序」** 选项：
  - **最近更新**：按目录修改时间排序（升降序可切）。
  - **名称**：按漫画标题排序（升降序可切）。
- 顶部搜索框可按标题关键字过滤。

> 提示：排序依据是「目录的修改时间」。如果你在某台设备通过本 App 的云同步**上传**漫画，修改时间会自动更新；手动用其它工具往服务器放文件时，修改时间取决于服务器/工具，个别服务器不返回该字段时会回退成「原始顺序」。

## 四、超分（画面增强）使用

超分是把漫画图片在本地用 GPU 实时放大/增强（本版本内置 **Anime4K ACNet** 模型，输出固定 **2 倍**），**完全在手机本地完成，不上传任何图片**，关掉时解码链路与官方完全一致。

### 在哪里开关

超分是**阅读器内**的设置，不在全局设置里：

1. 打开任意漫画进入阅读页。
2. 点右上角 **齿轮（阅读设置）**。
3. 切到 **「色彩 / 滤镜」** 那一页，最下方有超分相关开关。

### 两个开关

| 开关 | 作用 |
|---|---|
| **画面增强** | 总开关。打开后，你**滑到的页面**会实时超分。关掉即恢复原始画质。 |
| **整话超分** | 打开后，进入章节时把**整章每一页**都提前丢进超分队列并写入缓存（不只是你滑到的几页）。适合想要「整本都清晰」且不在意一进章先跑一阵 GPU 的场景。**它依赖「画面增强」总开关**，总开关关时本项不生效。 |

### 可调参数（仅「画面增强」打开后显示）

- **预载页数**：进入阅读时提前超分几页（默认 3）。值越大，翻页越跟手，但更吃内存。
- **GPU 性能模式**：
  - 全速（默认）：最快。
  - 50%：兼顾省电与速度。
  - 30%：最省电，最慢。
- **分块大小（Tile）**：GPU 处理图像的分块边长（64–256）。一般保持默认；老设备或显存小可试调小。
- **精度**：
  - **FP16**（默认）：速度更快。
  - **FP32**：更稳。
  - 多数设备 FP16 即可；若发现某些机型画面出现**规则噪点/灰点**，把精度切到 **FP32** 即可消除（这是部分 GPU 上 FP16 融合实现的已知差异，不是图片本身问题）。
- **处理分辨率上限**（宽/高，0 = 不限制）：超过该尺寸的图会先缩小再超分，用来给超大原图减负。
- **超过分辨率跳过**（宽/高）：超过该尺寸的图**直接不超分**，原样显示（适合已经很大、超分无意义的高清图）。
- **显示处理状态**：打开后阅读页会显示「超分处理中 / 已完成」之类提示，方便确认是否在生效。

### 使用建议

- 在线源、已下载章节、本地图源、**WebDAV 云盘** 全都支持超分。
- 想「整本都清晰、进章即备好」→ 打开 **整话超分**。
- 只想「看着哪页清哪页、最省电」→ 只开 **画面增强**，关掉整话超分。
- 嫌发热/耗电 → 把 GPU 性能模式调到 50% 或 30%。

## 五、整本下载

在漫画详情页，点下载按钮弹出的菜单里，除了原来的「未下载章节」，新增了 **「整本下载」**：一键把该漫画**所有未下载的章节**加入下载队列，不用一章章点。

## 六、常见问题（FAQ）

**Q：浏览里找不到「WebDAV 云盘」？**
A：先确认「设置 → 下载 → 云同步」总开关已开、账号已填且连接成功、目录已选。这三项齐了源里才会有内容。

**Q：列表里漫画是空的？**
A：检查「云同步目录」是否选对了——App 只把该目录的**直接子目录**当漫画。如果你选的是更上层的目录，而漫画还在下一层，就会看不到。

**Q：封面不显示？**
A：在每个漫画文件夹里放 `cover.jpg / cover.webp / cover.png / cover.jpeg` 之一。封面是滑到才加载，首次可能要等一两秒；列表是懒加载，不会一次性下载全部封面。

**Q：点进漫画详情后封面消失、返回列表也全空了？**
A：这是早期版本的 bug，已修复。当前版本详情页不再改写封面路径，列表/详情共用同一条封面通道，不会出现此问题。若仍遇到，请确认用的是最新 `MIhonA.apk`。

**Q：WebDAV 上看漫画要先把整本 CBZ 下到手机吗？**
A：不需要一次性搬整库。App 会在你打开某一章时，把那一本归档/电子书流式下载到应用**缓存**目录再读，读完翻到下一章就下下一章；只缓存你看过的章节。

**Q：清缓存会把我的设置 / 书架 / WebDAV 账号也清掉吗？**
A：不会。Android 里「**清除缓存**」和「**清除数据**」是两回事：
- **清除缓存**（设置 → 应用 → 存储 → 清除缓存）：只删缓存目录，也就是你看过的章节 CBZ 临时文件，**设置、书架、已登录的 WebDAV 账号都不受影响**。空间不够时清这个即可。
- **清除数据 / 清除存储**：才会把整个应用重置（配置、数据库、本地下载一并清空），相当于恢复出厂。**这个别点**。

> 小注：封面缩略图极小，存在应用私有「文件」目录（不在缓存目录），所以「清除缓存」清不掉它们；一般不用管，想彻底腾空间才用「清除数据」（但会重置应用）。

**Q：超分开着但画面有灰点/噪点？**
A：把「精度」从 FP16 切到 **FP32**（见第四节）。这是部分 GPU 上 FP16 融合的已知差异。

**Q：超分要联网吗？**
A：不需要。超分是纯本地 GPU 运算，图片不出本机。
